# Dataset

This project uses the **SMS Spam Collection** from the UCI Machine Learning Repository:
https://archive.ics.uci.edu/dataset/228/sms+spam+collection

1. Download and unzip the dataset.
2. Place the file named `SMSSpamCollection` in this folder as `SMSSpamCollection.txt`.

The file is tab-separated with no header: the first column is the label (`ham` or `spam`) and the second is the message text.

The dataset itself is not committed to the repository (see `.gitignore`).
